### Règles de communication D-003

1. Transmissions directes selon le flux : GAP → Solution ; GAP → Blueprint ; Solution → Blueprint ; Blueprint → QA ; QA → Blueprint (corrections) ; QA → Manager (« BPR validé QA »). Questions bloquantes possibles entre collègues ; tout le monde peut solliciter le Consultant Projet Support.
2. Chaque transmission indique la branche et le chemin du fichier, plus un résumé en 3 lignes maximum.
3. Le PM est mis en copie de chaque transmission de livrable (court message : quoi, à qui, où).
4. Pas de message de politesse ni d'accusé de réception. Au-delà de 3 allers-retours sur un même sujet, escalade vers le PM.
5. Périmètre, priorités et planning restent de la responsabilité du PM ; validations finales à Moustafa. Le PM peut réattribuer ou arbitrer à tout moment.
